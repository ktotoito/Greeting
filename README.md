### Общее описание
Greeting - это расширение для Visual Studio Code, которое пассивно-агрессивно приветствует пользователя, если он не открывал Visual Studio Code дольше определённого времени. Если же пользователь отсутствовал недолго, то расширение приветствует его как обычно.

### Подробное описание

Если пользователь не заходил в Visual Studio Code дольше определённого времени, то при открытии программы в новом окне высветится изображение в формате GIF с недовольной Ферн, одной из героинь аниме "Провожающая в последний путь Фрирен", и подписью "Где вы были больше `{time_interval}`?"

Если же пользователь заходит в Visual Studio Code регулярно, то при открытии программы выскакивает информационное окошко с подписью "♡ Добро пожаловать! ♡"

Пользователь может выбирать продолжительность периода возможного отсутствия без агрессивно-пассивного приветствия, что подробно описано в разделе "Команды".

---

#### Команды

 ##### ```Change Interval ```
Позволяет изменить допустимое время отсутствия, по прошествии которого будет показываться пассивно-агрессивное приветствие. Доступны значения в одну минуту (для демонстрации работы), один час, один день, одну неделю и один месяц.

##### ```Picked Interval```
Позволяет увидеть, какой допустимый период отсутствия (минута, час, день, неделя, месяц) выбран в данный момент.

### Инструкция по установке

#### Вариант 1 Сборка самостоятельно

1. Скачате проект и откроте его в VS Code

2. Установите ```vsce``` (VS Code Extension Manager)
```
npm install -g @vscode/vsce
```

3. В корне проекта выполните команду:
```
vsce package
```

После этого появится файл `greeting-0.0.1.vsix`

4. Установите расширение в VS Code:
```
code --install-extension mini-counter-0.0.1.vsix
```

#### Вариант 2 Скачать готовый файл

1. Перейдите в Releases и скачайте `greeting-0.0.1.vsix`
2. Запустите VS Code и откройте палитру команд `(Ctrl + Shift + P)`
3. Введите команду `Extensions: Install from VSIX...`
4. Укажи путь к скачанному `.vsix` файлу.
